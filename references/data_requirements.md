# 数据需求

## 最低可运行

- dataset registry
- sample/site metadata
- microbiome summary 或 sample-level matrix

## 点位环境匹配

额外需要：

- verified latitude
- verified longitude
- sampling date

## 正式微生物统计

额外需要：

- sample-level feature matrix
- taxonomy
- sample metadata
- grouping/repeated-measure structure

## Source tracking

额外需要：

- sample-level feature table
- source/sink labels
- negative controls（强烈建议）
- 统一 taxonomy/feature space
