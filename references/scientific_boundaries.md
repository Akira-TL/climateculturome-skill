# 科学边界

必须避免：

- correlation → causation
- shared occurrence → transfer
- altitude → independent oxygen mechanism
- spatial gradient → temporal climate response
- group means → sample-level significance
- database match → experimental validation
- model projection → deterministic future

推荐措辞：

- observed pattern
- descriptive candidate
- consistent ordering
- hypothesis-generating
- requires validation
- supported within current data boundary
