# Glossary

- **niche / 生态位**：宿主、植物、土壤、水体等不同微生物栖息环境。
- **shared occurrence**：同一分类单元在多个生态位被检测到。
- **source tracking**：利用样本级组成估计潜在来源贡献的方法。
- **environmental axis**：多个相关环境变量压缩形成的复合解释轴。
- **space-for-time**：以空间梯度近似时间变化的研究策略；只能作为假说框架，不能天然等同时间因果。
- **provenance**：数据、代码、参数、来源与处理过程的可追溯记录。
- **claim ledger**：科学主张与证据、边界、替代解释、下一步验证的结构化台账。
