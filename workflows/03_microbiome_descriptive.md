# 微生物组分析流程

## Summary-only 模式

输出：

- 主要门/属
- prevalence
- cross-niche shared occurrence
- descriptive ordering
- candidate outlier
- domain/niche pattern

禁止输出显著性。

## Sample-level 模式

在确认矩阵、metadata 和重复结构后，可进入：

- alpha diversity
- beta diversity
- PERMANOVA + PERMDISP
- differential abundance
- core microbiome
- source tracking
- network

所有 p-value 必须有明确来源和多重校正策略。
